# 🎮 Simon Says Game

## 🚀 Features

* Interactive color-based memory game
* Increasing difficulty levels
* Score tracking
* Key press to start game

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript

## 📦 Run Locally

Open simon.html in browser

## 📌 Description

This is a classic Simon Says memory game where users must remember and repeat a sequence of colors. The difficulty increases with each level.

## 🎯 Learning Outcome

* Event handling
* Game logic implementation
* DOM manipulation
